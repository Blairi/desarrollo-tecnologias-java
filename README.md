# Diplomado Java

Aquí reunimos todos los ejercicios, prácticas y proyectos que hemos desarrollado durante el curso.

## Estructura del Proyecto

Nuestro trabajo se encuentra organizado en dos carpetas principales que reflejan el progreso del diplomado.

## Semana1

En esta carpeta guardamos los ejercicios fundamentales que realizamos al inicio del curso. Aquí aprendemos los conceptos básicos de Java y practicamos con los siguientes temas:

- **Variables.java** - Declaración y uso de variables
- **Operadores.java** - Operadores aritméticos, lógicos y de comparación
- **Condicionales.java** - Estructura if, else y switch
- **Ciclos.java** - Bucles for, while y do-while
- **Arreglos.java** - Trabajo con arrays en Java
- **Funciones.java** - Definición y uso de métodos
- **Procedimientos.java** - Procedimientos sin retorno de valores
- **EntradaDeDatos.java** - Lectura de datos del usuario
- **Operadores.java** - Operadores en Java

Además, aquí practicamos con ejercicios más complejos como operaciones bancarias, cálculo de promedios e intercambio de variables.

## SegundaEntrega

En esta carpeta se encuentran los proyectos más avanzados del diplomado. Aquí profundizamos en conceptos orientados a objetos y estructuras de datos. Los archivos principales incluyen:

- **Herencia.java** - Conceptos de herencia entre clases
- **Polimorfismo.java** - Implementación de polimorfismo
- **Excepciones.java** - Manejo de excepciones y errores
- **Interfaz.java** - Trabajar con interfaces
- **Enumeraciones.java** - Uso de enumeraciones

Además, trabajamos con estructuras de datos importantes:

- **EjemploArrayList.java** - Listas dinámicas
- **EjemploLinkedList.java** - Listas enlazadas
- **EjemploCola.java** - Estructura de cola
- **EjemploPriorityQueue.java** - Colas con prioridad
- **EjemploHashMap.java** - Mapas de clave-valor
- **EjemploConjuntos.java** - Conjuntos (Sets)

También incluimos implementaciones personalizadas como:

- **Icrud.java** - Interfaz para operaciones CRUD básicas
- **IcrudAvanzado.java** - Extensión avanzada de operaciones CRUD
- **IControles.java** - Interfaz para controlar dispositivos

Finalmente, contamos con clases para modelar entidades del mundo real como clientes, productos y tarjetas, así como un paquete personalizado con clases y subclases para demostrar la organización de código en Java.

## Cómo Usar este Repositorio

Cada carpeta contiene un archivo de proyecto de IntelliJ (archivo .iml) y los códigos fuente en la carpeta src. Podemos compilar y ejecutar cada archivo Java de forma independiente o trabajar con el proyecto completo en el IDE.
